# IPL-Data-Analysis-Using-PySpark
## Introduction
This project provides a hands-on, end-to-end data engineering and analytics pipeline using an Indian Premier League (IPL) cricket dataset. The project architecture leverages Amazon S3 for scalable data storage, Databricks Community Edition for running Apache Spark (PySpark), and Python visualization libraries for data presentation.

It demonstrates ingestion, transformation, querying, and visualization of IPL data to offer key insights into player and team performances using real-world data processing methods.

 ## Technology Used

Programming Language: Python
Distributed Engine: Apache Spark (PySpark)

Cloud Platform: Databricks Community Edition

Storage: Amazon S3

Data Processing: PySpark DataFrames, SQL

Visualization: Pandas, Matplotlib, Seaborn

Notebook: Jupyter Notebook on Databricks
